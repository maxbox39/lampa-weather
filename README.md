# lampa-weather

Плагін для [Lampa](https://github.com/yumata/lampa-source): **віджет погоди** у шапці біля годинника.

Дані з [Open-Meteo](https://open-meteo.com/) — безкоштовно, **без API-ключа**.

![Lampa](https://img.shields.io/badge/Lampa-plugin-blue)
![Open-Meteo](https://img.shields.io/badge/API-Open--Meteo-orange)
![License](https://img.shields.io/badge/license-MIT-green)

---

## Встановлення

1. У Lampa відкрий **Налаштування → Розширення / Плагіни**.
2. Додай плагін:
https://raw.githubusercontent.com/maxbox39/lampa-weather/refs/heads/main/weather.js

3. Перезапусти Lampa.
4. Зайди в **Налаштування → Погода** і обери місто.
---

## Можливості

- Віджет у **верхній панелі**: іконка погоди + температура
- Пошук і вибір **будь-якого міста** (геокодинг Open-Meteo)
- Одиниці: **°C** або **°F**
- Автооновлення: кожні 15 / 30 / 60 / 120 хвилин
- Клік по віджету — короткі деталі:
  - місто
  - температура
  - вологість
  - вітер
- Кеш останніх даних (показує, якщо немає мережі)
- Кнопка **«Оновити зараз»** у налаштуваннях

---

## Налаштування

**Налаштування → Погода**

| Параметр | Опис |
|----------|------|
| Показувати віджет | Увімкнути / вимкнути віджет у шапці |
| Місто | Пошук і вибір міста |
| Одиниці температури | °C або °F |
| Оновлювати кожні | Інтервал запиту до API |
| Оновити зараз | Примусове оновлення погоди |

---

## Джерело даних

- Прогноз: [Open-Meteo Forecast API](https://open-meteo.com/)
- Міста: [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- Реєстрація і ключ **не потрібні**

---

## Сумісність

- Lampa з підтримкою `SettingsApi`, `Head` / шапки, `Select`, `Input`
- Коректне повернення фокусу після вибору міста (TV / пульт)

---

## Примітки

- Для роботи потрібен доступ клієнта Lampa до інтернету
- Якщо віджет не з’явився — перевір, що він увімкнений у налаштуваннях, і перезапусти додаток
- Назва міста в шапці схована навмисно (лише іконка + температура); місто видно по кліку
